📤 Bulk Add Students
Download the template, fill in one row per student (Name and Class are required; everything else is optional), then upload it here. Student IDs are generated automatically — don't fill that column in yourself. The template also has Billed/Discount columns for each active fee head — fill those in too if you want fees set at the same time (leave blank to add fees later from the student's profile instead).
✏️ Edit Fees — –
Set or correct the billed amount for each fee head. This is the amount owed — payments already recorded stay exactly as they are and are tracked separately. Saving a head here resets any earlier discount on it to zero; heads you leave untouched are not affected at all.

📅 Add Calendar Entry
Holidays are removed from working days; a "Working Day" entry adds a normally-off day (e.g. a working Sunday) back. Use End Date for a multi-day break or an exam window.
🔁 Add Recurring Holiday
Generates one "Holiday" entry per matching date across the range (e.g. every 2nd Saturday from June to March) so you don't have to add each one by hand. Use the academic year's start/end as From/To.
